# Separate-Chaining Hash Table Viewer (C# .NET 8.0 Windows Forms)

تطبيق ومحاكي كامل مكتوب بلغة C# (.NET 8.0 Windows Forms) يعيد إحياء بريمج جافا التاريخي لروبرت لافور:
**Separate-Chaining Hash Table Applet (Chapter 11: Hash Tables)**
من كتاب: *Data Structures & Algorithms in Java (1998)*.

---

### المميزات الأساسية:
1. **تمثيل السلاسل المنفصلة (Separate Chaining):**
   - مصفوفة دلاء (Buckets) يحتوي كل منها على قائمة مترابطة (Linked List) بسعة تصل إلى 6 عناصر.
   - دالة التجزئة: `key % totalBuckets`.
   - إدراج العناصر في رأس القائمة المترابطة (Head insertion) في زمن فوري $O(1)$.
2. **شريط تمرير رأسي (VScrollBar):**
   - تنقل بين 10 دلاء مرئية في شاشة العرض من أصل حتى 100 قائمة، مع تحريك تلقائي للتمرير عند تنفيذ العمليات على قوائم بعيدة.
3. **العمليات الكاملة:**
   - `New`: إنشاء جدول جديد بعدد $N$ من القوائم (حتى 100).
   - `Fill`: تعبئة الجدول بـ $N$ من العناصر العشوائية.
   - `Ins`: إدراج عنصر بالمفتاح $N$.
   - `Del`: حذف عنصر بالمفتاح $N$ من سلسلته مع إزاحة العقد اللاحقة.
   - `Find`: بحث متسلسل بالسهم الأحمر عبر روابط السلسلة.
   - `Step` & `Run`: تشغيل الخوارزمية خطوة بخطوة أو آلياً مع التحكم بالسرعة.

### متطلبات التشغيل:
- .NET 8.0 SDK أو أحدث
- Visual Studio 2022 أو Visual Studio Code (مع إضافة C# Dev Kit)

### التشغيل عبر سطر الأوامر:
```bash
dotnet build
dotnet run
```
