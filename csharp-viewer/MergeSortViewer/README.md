# Robert Lafore Merge Sort Workshop (Divide & Conquer)
# مشروع الترتيب بالدمج بلغة C# .NET 8 Windows Forms

مشروع تطبيقي كامل بلغة C# (.NET 8.0 Windows Forms) يُحاكي بدقة متناهية بريمج جافا التعليمي الكلاسيكي لروبرت لافور من الفصل الثامن (**Data Structures and Algorithms in Java - Chapter 8: Merge Sort**).

## المميزات الفنية المطبقة:
1. **خوارزمية الترتيب بالدمج (Merge Sort):**
   - تقسيم عودي متوازن للمصفوفة إلى نصفين (Lower & Upper) حتى الوصول لمصفوفات بحجم 1.
   - دمج النصفين المرتبين إلى مصفوفة عمل مؤقتة (`workSpace`).
   - نسخ عناصر مصفوفة العمل بالكامل مرة أخرى إلى المصفوفة الأصلية.
2. **كفاءة زمنية مضمونة:**
   - تعمل الخوارزمية بزمن $O(N \log N)$ مضمون في جميع الحالات (الأفضل، المتوسط، والأسوأ).
3. **مكدس استدعاءات صريح (Explicit Stack & Params):**
   - محاكاة دقيقة للاستدعاءات العودية وتخزين معالم `lower` و `upper` و `mid` وعنوان العودة `codePart` عبر كلاس `Params` ومكدس `Stack`.
4. **رسم ومؤشرات تفاعلية:**
   - رسم الأعمدة بأسلوب AWT 3D الكلاسيكي مع مؤشرات ملونة (`lower`, `upper`, `mid`, `ptr`).
   - خط أزرق/أسود يوضح النطاق الجزئي النشط حالياً.
5. **إحصائيات فورية:**
   - عداد المقارنات (Comparisons) وعداد النسخ (Copies).

## كيفية التشغيل عبر سطر الأوامر:
```bash
cd MergeSortViewer
dotnet run
```
