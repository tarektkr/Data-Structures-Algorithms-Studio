# TowersViewer (.NET 8 Windows Forms)

مشروع محاكي **أبراج هانوي (Towers of Hanoi)** المستخرج والمعاد بناؤه بلغة C# من كتاب **Data Structures & Algorithms in Java** لمؤلفه **Robert Lafore** (الفصل السادس: العودية ومحاكاة مكدس الاستدعاءات).

## الميزات:
1. **محاكاة مكدس الاستدعاءات الصريح (CallStack)**:
   - تمثيل حقيقي للعودية بدون مخاطر طفحان الذاكرة باستخدام كلاس `CallStack` وكلاس `Params` (يحفظ `n`, `from`, `to`, `inter`, و `codePart` كنقطة عودة).
2. **سحب وإفلات تفاعلي بالأقراص (Interactive Drag & Drop)**:
   - إمكانية تجربة حل اللغز يدوياً بنقر وسحب الأقراص بين الأعمدة A و B و C.
   - التحقق الفوري من قواعد هانوي (لا يمكن وضع قرص أكبر فوق قرص أصغر).
3. **التشغيل الآلي خطوة بخطوة (Step & Run)**:
   - زر `Step`: تنفيذ خطوة واحدة ومتابعة تحركات مكدس العودية.
   - زر `Run`: تشغيل الخوارزمية آلياً مع التحكم بالسرعة.
4. **تخصيص عدد الأقراص (New with N disks)**:
   - دعم من 1 إلى 10 أقراص وحساب عدد الحركات الأدنى $2^N - 1$.

## كيفية التشغيل:
```bash
dotnet build
dotnet run
```
متوافق مع Visual Studio 2022 و .NET 8.0 SDK.
