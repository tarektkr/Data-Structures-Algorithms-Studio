# Lafore's Linked List Workshop Applet - C# Windows Forms Viewer

مشروع C# Windows Forms تفاعلي عالي الدقة لإعادة إحياء وتطبيق بريمج ورشة العمل **Linked List (القائمة المترابطة)** من الفصل الخامس لكتاب *Data Structures and Algorithms in Java* لمؤلفه روبرت لافور (Robert Lafore).

## ميزات المشروع (Key Features)

- **دعم النمطين: غير المرتب (Unsorted) والمرتب (Sorted)**:
  - في القائمة غير المرتبة: يتم الإدراج (`Ins`) في رأس القائمة (`Head/First`) في زمن ثابت $O(1)$.
  - في القائمة المرتبة: يتم البحث عن الموضع الصحيح تنازلياً وإدراج العنصر مع إعادة ربط المؤشرات.
- **تمثيل هندسي شبكي ثنائي الأبعاد**:
  - شبكة من 4 صفوف في 7 أعمدة (حتى 28 عقدة كحد أقصى).
  - أسهم ربط أفقية بين العقد، وأسهم التفاف ثعبانية (Serpentine Wrapping) عند نهاية كل صف للانتقال للصف التالي.
  - مؤشر أحمر `current / curIn` يشير إلى العقدة التي يتم فحصها حالياً.
  - تحريك وإعادة توجيه المؤشرات مرئياً أثناء الإدراج (Splice) وأثناء الحذف (Bypass).
- **العمليات المطبقة (Supported Operations)**:
  - `New`: إنشاء قائمة جديدة بحجم N محدد (حتى 28 عنصر) واختيار حالة الترتيب (Unsorted/Sorted).
  - `Ins`: إدراج عنصر جديد بالمفتاح N مع إظهار خطوات الوصل.
  - `Find`: البحث الخطي عن عنصر ومتابعته خطوة بخطوة عبر العقد.
  - `Del`: حذف العنصر ذي المفتاح N مع إظهار قفز المؤشر متجاوزاً العقدة المحذوفة.
- **واجهة Windows Forms كلاسيكية**: مطابقة تماماً لواجهة البريمج الأصلي مع دعم Double Buffering لمنع وميض الشاشة.

## كيفية التشغيل (How to Run)

1. افتح موجه الأوامر (Command Prompt أو Terminal) في هذا المجلد:
   ```bash
   dotnet build
   dotnet run
   ```
2. أو افتح مجلد المشروع في Visual Studio أو Rider واضغط F5.
