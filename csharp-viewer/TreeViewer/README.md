# Robert Lafore's Binary Tree Workshop (Chapter 9) - C# Windows Forms

مشروع تطبيقي متكامل بلغة **C# .NET 8.0 Windows Forms** يحاكي بريمج شجرة البحث الثنائية الأصلية (Binary Tree Applet) من كتاب **Robert Lafore: Data Structures and Algorithms in Java (Chapter 9)**.

## المميزات الهندسية:
1. **تمثيل الشجرة بمصفوفة كاملة بحجم 31 عقدة (Array-based BST)**:
   - الجذر عند الفهرس `0`.
   - الابن الأيسر عند `2 * i + 1`.
   - الابن الأيمن عند `2 * i + 2`.
   - الأب عند `(i - 1) / 2`.
2. **العمليات الكاملة المطابقة لبايت كود جافا الأصلي**:
   - `Fill`: توليد شجرة جديدة بعدد N من العقد بمفاتيح غير مكررة (0-99).
   - `Find`: البحث عن العقدة خطوة بخطوة مع تحريك مؤشر السهم الأحمر لليسار أو لليمين في زمن $O(\log N)$.
   - `Ins`: إدراج عقدة جديدة في الموضع الصحيح مع كشف تجاوز العمق المسموح به (5 مستويات).
   - `Trav`: التجوال المرتب تصاعدياً (Inorder Traversal) باستخدام مكدس استدعاءات LIFO صريح غير عودي (`Stack.cs`) وعرض النتائج في صندوق الزيارة السفلي.
   - `Del`: حذف العقدة مع الحالات الثلاث الكلاسيكية:
     - الحالة 1: عقدة ورقية (Leaf) بدون أبناء.
     - الحالة 2: عقدة ذات ابن وحيد (إزاحة الشجرة الجزئية للأعلى `MoveUpSubTree`).
     - الحالة 3: عقدة ذات ابنين (استبدالها بالخليفة اللاحق في الترتيب `InorderSuccessor`).
3. **التشغيل الآلي والخطوة بخطوة**:
   - زر `Step` للتنفيذ خطوة بخطوة.
   - زر `Run / Pause` للتشغيل التلقائي المستمر.
   - النقر بالماوس على أي عقدة لنسخ قيمتها تلقائياً إلى حقل الإدخال.

## متطلبات التشغيل:
- .NET 8.0 SDK أو أحدث.
- Visual Studio 2022 أو Visual Studio Code.
- للتشغيل من سطر الأوامر:
  ```bash
  dotnet run
  ```
