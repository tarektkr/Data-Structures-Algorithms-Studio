# Lafore's Priority Queue Workshop Applet - C# Windows Forms Viewer

مشروع C# Windows Forms تفاعلي عالي الدقة لإعادة إحياء وتطبيق بريمج ورشة العمل **Priority Queue (طابور الأولوية)** من الفصل الرابع لكتاب *Data Structures and Algorithms in Java* لمؤلفه روبرت لافور (Robert Lafore).

## ميزات المشروع (Key Features)

- **بنية طابور الأولوية المعتمد على مصفوفة مرتبة**:
  - تمثيل العناصر بالترتيب التصاعدي بحيث يتواجد العنصر ذو الأولوية القصوى دائماً في المقدمة (`Front = NPersons - 1`).
  - مؤشر `Rear = 0` ثابت في أسفل المصفوفة (يشير إلى أقل عنصر).
  - مؤشر `Front = NPersons - 1` يشير إلى العنصر الأكبر في قمة الطابور.
  - مؤشر `curIn` (سهم أسود بطول 10) يوضح خطوات البحث والمقارنة وإزاحة العناصر (`Shift`).
- **العمليات المطبقة (Supported Operations)**:
  - `New`: إنشاء طابور أولوية فارغ جديد وتصفير المؤشرات.
  - `Ins`: إدراج عنصر بالبحث التنازلي وإزاحة العناصر الأكبر للأعلى بخوارزمية الإدراج المباشر $O(N)$.
  - `Rem`: سحب وحذف العنصر ذو الأولوية القصوى من المقدمة في زمن ثابت $O(1)$.
  - `Peek`: معاينة العنصر الأكبر دون حذفه في زمن ثابت $O(1)$.
- **واجهة Windows Forms كلاسيكية**: مطابقة تماماً لواجهة البريمج الأصلي مع دعم Double Buffering لمنع وميض الشاشة.

## كيفية التشغيل (How to Run)

1. افتح موجه الأوامر (Command Prompt أو Terminal) في هذا المجلد:
   ```bash
   dotnet build
   dotnet run
   ```
2. أو افتح مجلد المشروع في Visual Studio أو Rider واضغط F5.
